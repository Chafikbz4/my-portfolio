# Chafik Bouzaghou — Portfolio

A Kali Linux–style file-explorer portfolio. Everything is browsed like a real
file tree: `~/software-engineering/academic-projects/DZ-Skills.md`, etc.

**No build step needed to host it.** `index.html` is fully self-contained —
your images and the app code are embedded directly in it — so it works
straight away on any static host, and even opened locally by double-click.

## Project structure

```
portfolio/
├── index.html            → ⭐ the file to deploy. Self-contained (images +
│                            app code inlined). Generated by build.py — don't
│                            hand-edit it, edit the source files below instead.
├── index.template.html    → HTML shell used to generate index.html
├── styles.css             → the Kali-inspired theme (colors, layout, animations)
├── data.js                → ALL editable content: profile, projects, internships,
│                            cybersecurity achievements, certifications
├── app.js                 → the React components (sidebar, cards, modal, search…)
├── assets.js              → generated: your images, base64-embedded
├── assets/                → the original image files (source of truth for assets.js)
└── build.py                → regenerates assets.js and index.html — run this
                              after any edit to app.js or to a file in assets/
```

## How to add or edit content (no coding needed)

Open **`data.js`**. Every project / internship / achievement is one object
in an array. Copy an existing block, change the text between the quotes,
save, and refresh `index.html` in your browser — `data.js` is loaded
separately, so this alone doesn't need a rebuild.

To add or change a **cover image**:
1. Drop the image file into `assets/`.
2. Add a line for it in `ASSET_FILES` at the top of `build.py` (copy an existing line).
3. Reference it in `data.js` as `IMG.yourKeyName`.
4. Run `python3 build.py`.

If you edit **`app.js`** (the components), also run `python3 build.py`
afterwards — it re-embeds the latest app.js into index.html.

```bash
cd portfolio
python3 build.py
```

## Run it locally

Just open `index.html` in a browser — no server required. (You can also
serve it with `python3 -m http.server 8080` if you prefer.)

## Publish it for free (pick one)

**Netlify Drop — fastest, no account needed to preview**
1. Go to https://app.netlify.com/drop
2. Drag the whole `portfolio` folder onto the page.
3. You get a live URL immediately (you can claim/rename it with a free account).

**GitHub Pages — best if you already use GitHub**
1. Create a new repository, e.g. `chafikbz4.github.io` (that exact name gives you `https://chafikbz4.github.io`), or any repo name for a project page.
2. Push these files to the repo's default branch.
3. Repo → Settings → Pages → Source: select the branch and `/ (root)`.
4. Your site is live at the URL GitHub shows there within a minute or two.

**Vercel**
1. Go to https://vercel.com/new
2. Import the repo (or drag-and-drop the folder via the Vercel CLI: `npx vercel`).
3. No build command needed — framework preset "Other" / static.

Any of these gives you a shareable HTTPS link to put on your CV or LinkedIn.
